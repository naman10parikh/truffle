# Fixing error 0x80070005 (Access Denied)

The Windows error code 0x80070005 means "Access Denied". It appears during
Windows Update, app installs, or activation when the SYSTEM account lacks
permission to a registry key or folder. To resolve 0x80070005: run the update
troubleshooter, reset the SoftwareDistribution folder, and re-grant SYSTEM full
control on the affected path. The exact string 0x80070005 is the diagnostic key.
